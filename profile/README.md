# NDDev OpenNetwork

Open engineering, shared tools and public hackathon projects from NDDev.

## Engineering

- [GitHub Device Sync](https://github.com/NDDev-Technocracy-OpenNetwork/github-device-sync) — repository policy, agent context and reproducible Git workflows.
- [CI workflows](https://github.com/NDDev-Technocracy-OpenNetwork/ci-workflows) — pinned reusable build and security checks.
- [Sysinfo](https://github.com/NDDev-Technocracy-OpenNetwork/sysinfo) — system information tooling.
- [NDS](https://github.com/NDDev-OpenNetwork-NDS) — the separate organization for open device synchronization development.

## Hackathons

Event projects use `hack-<year>-<event>`; a product or team suffix distinguishes multiple implementations. Shared tooling keeps an event-independent name. These are historical prototypes and post-event maintenance copies: check each README for setup and the integrations that need your own credentials.

| Repository | Purpose |

| [hack-2025-ai-auditor](https://github.com/NDDev-Technocracy-OpenNetwork/hack-2025-ai-auditor) | NFNG 2025 hackathon prototype: Curestry prompt analysis, validation and optimization. FastAPI + Next.js. |

| [hack-2026-nornickel](https://github.com/NDDev-Technocracy-OpenNetwork/hack-2026-nornickel) | Nornickel AI Hack 2026: evidence-backed research knowledge graph and retrieval workbench for mining and metallurgy. |

## Contributing

Start with the repository's contributing guide; otherwise use our shared [CONTRIBUTING](../CONTRIBUTING.md). Changes go through pull requests, third-party actions are pinned, and public CI runs on hosted runners. Security-sensitive operations require the owner's explicit authorization.
